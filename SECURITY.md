# Segurança

## Escopo

Este é um projeto educacional local. O arquivo entregue:

- não contém macros;
- não executa código ao ser aberto;
- não possui vínculos externos de pasta de trabalho;
- não requer API, servidor ou credencial;
- não envia dados pela rede.

## Relato responsável

Se encontrar risco de segurança, evite publicar detalhes exploráveis em uma issue. Entre em contato pelo perfil do autor no GitHub e descreva:

- arquivo ou componente afetado;
- passos para reproduzir;
- impacto potencial;
- correção sugerida, se houver.

## Dados

A base do desafio é pública e educacional. Não substitua seu conteúdo por dados pessoais reais sem anonimização, controle de acesso e política de retenção apropriados.
